# Menú semanal

App de iOS para planificar el menú de la semana (comida y cena, de lunes a domingo), con widget para la pantalla de inicio.

- SwiftUI, datos solo en el dispositivo.
- Widget (pequeño y mediano) con la semana y el día actual resaltado.
- Sin cuentas, sin servidores, sin rastreo.

## Instalación (AltStore)

1. Abre AltStore y ve a **Fuentes**.
2. Añade esta fuente:
   `https://raw.githubusercontent.com/Pradaxa/menu-semanal/main/altstore/source.json`
3. Instala **Menú** desde la fuente. Las actualizaciones aparecerán en AltStore automáticamente.
